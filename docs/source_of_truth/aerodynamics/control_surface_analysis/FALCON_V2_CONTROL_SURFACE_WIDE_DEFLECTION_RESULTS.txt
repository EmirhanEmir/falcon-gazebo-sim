FALCON V2 — CONTROL SURFACE WIDE-DEFLECTION ANALYSIS RESULTS
================================================================

Purpose
-------
This file consolidates ALL results obtained in the current XFLR5 control-surface
wide-deflection analysis for:
1) Elevator
2) Aileron
3) Rudder

All listed values below are from the analyses performed in this conversation.
No points have been intentionally omitted.

Common analysis method
----------------------
XFLR5
Type 1 (Fixed speed)
3D-Panels / VLM2
Viscous = OFF
Mass = 6.000 kg

Primary operating point used for wide-deflection sweeps:
V∞ = 18.162 m/s
alpha = 2.472 deg (XFLR5 display: 2.47 deg)
beta = 0 deg

Only the tested control surface was deflected.
Other control surfaces were held at 0 deg.

Confidence convention
---------------------
|delta| <= 10 deg:
  HIGH_CONFIDENCE_SMALL_SIGNAL

10 deg < |delta| <= ~25 deg:
  MEDIUM_CONFIDENCE_NONLINEAR_REFERENCE

|delta| > ~25 deg:
  LOW_CONFIDENCE_HIGH_DEFLECTION_REFERENCE

Important:
Large-deflection XFLR5 / VLM results are not treated as direct real-flight truth,
because separated flow / stall / hinge-region nonlinearities are not fully modeled.

Elevator conclusions
--------------------
- Small-angle CL and Cm effectiveness are extremely consistent across +/-2, +/-5, +/-10 deg.
- Secondary operating point gives nearly identical derivatives.
- Positive XFLR5 elevator deflection increases CL and drives Cm negative.
- CD is nonlinear with deflection and is better represented by lookup/interpolation.
- >25 deg is low-confidence high-deflection reference.
- Old trim-sweep Cm_delta_e ~ -0.73 /rad is not the pure fixed-condition control-effectiveness result.
- New fixed-condition value is approximately Cm_delta_e = -1.000 /rad.
- Previously unresolved CL_delta_e is now approximately +0.414 /rad.
