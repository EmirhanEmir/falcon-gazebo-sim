================================================================
1. PROJE KAPSAMI
================================================================

Uçak:
Titan Dynamics Falcon V2 — conventional tail

Hedef:
Gazebo Sim Harmonic + ArduPlane SITL içinde mümkün olduğunca gerçek fiziğe yakın
6-DOF sabit kanat UAV modeli.

İtki modeli sabit "throttle -> Newton" tablosu olmayacak.

Hedef propulsion zinciri:
Throttle
-> ESC duty-cycle / uygulanan ortalama gerilim
-> motor elektrik modeli
-> motor akımı
-> motor elektromanyetik torku
-> motor + pervane angular dynamics
-> RPM(t)
-> propeller advance ratio J
-> APC Ct(J), Cp(J)
-> thrust + aerodynamic prop torque
-> reaction torque
-> gerçek propeller hub konumundan kuvvet/moment
-> Gazebo 6-DOF dynamics
